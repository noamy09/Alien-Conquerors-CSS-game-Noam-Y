# Alien-Conquerors-CSS-game-Noam-Y.

We created a full CSS game inspired by flexbox froggy. the answers for each level are as such:
1. justify-content: end;
2. justify-content: space-between;
3. flex-wrap: wrap;
4. justify-content: center;
align-items: center;
5. justify-content: space-around;
align-items: flex-end;
6. flex-direction: row-reverse;
justify-content: start;

some levels accept multiple variations (like end or flex end at the first level) and some don't as they would'nt work in the esact situation.
